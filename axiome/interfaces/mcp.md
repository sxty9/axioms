Jeder Service stellt seine Fähigkeiten als vollständige MCP-Schnittstelle bereit — als Model-Context-Protocol-Server, über den Agenten die Funktionen des Service nutzen. Der Server ist einheitlich benannt und über die zentrale Infrastruktur adressierbar, analog zur zentralen Rechteverwaltung; seine Adresse liegt server-seitig und nie im Request, sodass kein manipulierter Aufruf einen Agenten auf einen fremden Host lenkt. Jede über MCP angebotene Fähigkeit ist durch das Rechtesystem gedeckt.

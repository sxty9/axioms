titel: Reuse before Build
---
1. Suche die benötigte Komponente zuerst im geteilten SDK.
2. Existiert eine ähnliche: erweitere die SDK-Komponente.
3. Existiert keine, wird sie aber domänenübergreifend gebraucht: baue sie im SDK.
4. Nur wenn sie hochspezifisch für genau diesen Service ist: baue sie lokal.
